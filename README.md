# Exploring-JavaScript-Spread-Syntax

Task 1: Function Argument Expansion
- Defines a sum function that takes three parameters.
- Uses spread syntax to pass array elements as arguments.
- Logs the computed sum.
Task 2: Merging Arrays
- Creates two arrays and merges them using the spread operator.
- Outputs the combined array.
Task 3: Array Element Insertion
- Inserts new elements at the beginning and end of an array using spread syntax.
- Logs the extended array.
Task 4: Cloning and Modifying an Object
- Creates a person object.
- Clones it using spread syntax.
- Modifies properties in the cloned object without affecting the original.
Task 5: Combining Objects
- Demonstrates how spread syntax handles property conflicts.
- Combines two objects into one.
